# RIFCLIMA · propuesta de web

Web de RIFCLIMA, instalaciones de frío y calor en Alzira (Valencia): aire acondicionado para casas y negocios, reparación de averías y cambio de equipos.

**Ver la web:** https://nocodya-hue.github.io/rifclima/

- HTML, CSS y JavaScript estáticos (GSAP + Lenis para el movimiento), tipografía Inter autoalojada.
- Las 17 reseñas son las de su ficha de Google, copiadas tal cual (`js/resenas.js`).
- El formulario está en modo de vista previa: no envía nada hasta configurar `FORM_ENDPOINT` en `js/main.js`.

> Web de muestra. Las fotos de trabajos son fotos reales de su ficha de Google retocadas con IA (luz, color y nitidez). Las imágenes del técnico, la furgoneta y el local están generadas con IA con su marca, provisionales hasta contar con fotos reales. El logo está redibujado en vectorial a partir de su tarjeta.
